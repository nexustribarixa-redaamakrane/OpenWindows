Boot transcripts (02/03) use the same QEMU serial-socket plumbing with no
input: boot the disk (or floppy) image, drain the serial stream until the
auto-init's final `status` and the `ow-krnl>` prompt, then write the bytes
verbatim (CRLF).  Transcript 05 is the equivalent VirtualBox serial log.

VirtualBox capture recipe (VirtualBox 7.2.16, headless):
  # Boot a byte-identical *copy* of the packaged VDI: opening a VDI rewrites
  # its header, so booting the packaged file in place would change its hash.
  copy images\openwinkrnl_tirimid_disk.vdi %TEMP%\ow_tirimid_vbox_copy.vdi
  VBoxManage storageattach OpenWindows-Tirimid --storagectl SATA --port 0 --device 0 --type hdd --medium %TEMP%\ow_tirimid_vbox_copy.vdi
  VBoxManage modifyvm OpenWindows-Tirimid --uart1 0x3F8 4 --uartmode1 file <serial.log>
  VBoxManage startvm OpenWindows-Tirimid --type headless
  VBoxManage controlvm OpenWindows-Tirimid screenshotpng screenshots\09-vbox-boot.png
  VBoxManage controlvm OpenWindows-Tirimid poweroff
